# Diwali Magic ✨ – The Ultimate Interactive Diwali Celebration Platform

> **"Light Up Happiness. Celebrate Together. Share the Magic. 🪔"**

**Diwali Magic ✨** is a premium, modern, visually stunning, fully responsive, and highly interactive Diwali festival web platform. Built with **React 19, Vite, Tailwind CSS v4, HTML5 Canvas API, and Web Audio API**, it delivers an authentic Indian cultural festival experience complete with working interactive studios, procedural audio, particle physics, and local storage persistence.

---

## 🌟 Key Features & Interactive Studios

- 🎆 **Entry Automatic Fireworks Celebration:**
  - Immersive 100% black night sky with automatic rocket launches and particle explosions.
  - Realistic velocity, gravity, drag, fading smoke, and sparkle persistence.
  - Golden glowing welcome banners and interactive click-to-burst sky.
  - Controls: Skip Intro, Replay Intro, Sound On/Off, and Enter Celebration. Respects reduced-motion preference.

- 🪔 **Virtual Diya Lighting Studio:**
  - Handcrafted clay diya styles: Mitti Clay Diya, Royal Brass Diya, Mayur Teal Diya, Kundan Ruby Diya, and Shahi Purple Diya.
  - Interactive flame ignition with animated CSS/SVG flame, sound effects, and radiant glow.
  - Name dedication and personal prayer.
  - Global Diya Wall of Light with session counters and persistent community lamps.
  - Export diya dedication as a high-resolution PNG image.

- 💌 **Personalized Wishes & Photo Greeting Studio:**
  - 7-Step Greeting Studio: Details $\to$ Relationship Category $\to$ Tone $\to$ Photo Upload $\to$ Card Theme $\to$ Live Preview $\to$ Share & Download.
  - Upload family photos (JPG, PNG, WebP) with zoom, scaling, and position adjustments.
  - 1-Click WhatsApp pre-filled greeting sharing, Web Share API with image attachments, and high-res PNG download.

- 🎇 **Diwali Fireworks Arena:**
  - Dedicated night sky simulator with 10 realistic firework categories:
    *Rocket, Flower Burst, Chrysanthemum, Willow Sparks, Crackling Sparkler, Peony Spherical, Ring Halo, Fountain Geyser, Shooting Comet, and Multi-Color Finale.*
  - Control console: Trajectories, explosion scale, timed shows (10s, 15s, 30s, 60s), auto-mode, and Grand Finale barrage.

- 🎨 **Digital Rangoli Creator Studio:**
  - Radial symmetry engine supporting Freehand, 4-Way, 8-Way, and 12-Way symmetry.
  - Traditional powder palette: Gulal Sindoor, Haldi Golden, Marigold Orange, Peacock Indigo, Emerald Green, Gulabi Pink, and Rice Flour White.
  - Undo/redo history, brush size controls, eraser, center emblem stamps (🪔 Diya, 🌸 Lotus, ॐ Om), and PNG download.

- 📋 **Diwali Celebration & Budget Planner:**
  - Celebration preference tailoring (Family, Traditional, Eco-friendly, Friends, Home Decor, Culinary).
  - Preparation, Shopping, Decoration, and Puja checklists with persistence.
  - 5-Day Festival Schedule & interactive budget expense tracker.

- 🙏 **Virtual Lakshmi-Ganesha Puja Guide & Digital Thali:**
  - Chronological 6-step Vedic Vidhi with sacred Sanskrit shlokas and translations.
  - Puja Samagri checklist.
  - Interactive Digital Puja Thali: Ring the temple bell with sound, shower flower petals, offer bhog prasad and holy Gangajal, and kindle the aarti flame.

- 🍬 **Diwali Sweets & Faral Delights:**
  - Authentic recipes: Kaju Katli, Shahi Besan Ladoo, Mawa Gulab Jamun, Crispy Chakli, Sweet Shankarpali, and Poha Chivda.
  - Search by ingredient/name, category filters, cooking steps modal, and favorite bookmarking.

- 🎮 **Diwali Games Zone:**
  - 1. *Diwali Trivia Quiz* with scoring, explanations, and badges.
  - 2. *Festive Memory Matching Game* with move counters and celebratory confetti.
  - 3. *Festival Word Scramble Puzzle* with cultural hints.

- 🏮 **Digital Lantern Designer (Akash Kandil):**
  - Geometric shapes: Star Kandil, Lotus Blossom, Diamond Hexagon, and Palace Drum.
  - Silk palettes, personalized greetings, streamer/tassel slider, live floating animation, and PNG export.

- 🏡 **Festive Home Decoration Designer:**
  - Virtual verandah decorator: toggle fairy lights, marigold torans, earthen floor diyas, floor rangolis, hanging lanterns, and brass urlis.

- 📜 **Diwali History & Sacred Traditions:**
  - Deep spiritual meaning, 5 sacred days of Diwali, and diverse regional traditions across India.

- 🎁 **Diwali Gift Discovery Corner:**
  - Thoughtful gift ideas filtered by recipient and budget (< ₹500, ₹500–₹1,000, ₹1,000–₹2,500, > ₹2,500).

- 🌱 **Green Diwali Challenge:**
  - Eco-friendly pledges (clay diyas, organic rangoli, planting trees, soundless fireworks) with achievement tracking.

- 📜 **Diwali Memory Wall:**
  - Community memory board for sharing photos, stories, and captions with reaction counters.

- 👤 **User Profile & My Diwali:**
  - Avatar & name customizer, saved creations gallery, and stats dashboard.

- 🎨 **Live Festive Theme Switcher (5 Curated Palettes):**
  - 🔴 **Shahi Crimson & Gold** (*Default*)
  - 🔵 **Midnight Peacock & Kohinoor Gold**
  - 🟠 **Vedic Saffron & Royal Amber**

  - Dynamic language switcher supporting English, Hindi (हिंदी), and Marathi (मराठी).

  - Procedural sound effects for rocket whistles, explosions, temple bells, crackles, and calming Indian classical ambient tanpura drone music.

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Animations & Effects:** HTML5 Canvas API + Web Audio API + canvas-confetti
- **Routing:** React Router v7
- **Persistence:** LocalStorage API

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Prafull044/Diwali-Website.git
   cd Diwali-Website
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to `http://localhost:5173/`

### Build for Production
```bash
npm run build
npm run preview
```
